# MultiDiseasePred — ED triage demo

Generated by multidiseasepred from a fitted model with 12 inputs and 9 outcomes.

```bash
pip install -r requirements.txt
streamlit run app.py
```

`variables.json` controls the input widgets. Edit the labels, units, defaults and ranges there; the app reads them at startup and nothing in `app.py` needs to change.

> **Synthetic demonstration.** This app was built by `examples/build_ed_dashboard.py` from simulated data, because the University of Minnesota encounters cannot leave the institution. The layout and the variables are real; the numbers are not model output and must not be quoted.
